Meridian Harbour International Bank — demo website
====================================================

Files:
- index.html   The full site (Home, About, Accounts, Security, Contact, Privacy, Terms).
               It's a single self-contained file — open it directly in any browser.
- robots.txt   Allows search engines to crawl the site.
- sitemap.xml  Lists the site URL for search engines.

Before going live:
1. Replace "https://www.meridianharbourbank.com" in index.html, robots.txt, and
   sitemap.xml with your real domain.
2. The login modal, contact form, and "Write a Review" button are front-end demos
   only — they don't connect to a real backend, database, or authentication system.
   Wiring those up requires real server infrastructure, which isn't included here.
3. Brand name, logo, and all images are original/fictional — safe to use as a
   starting point, but not tied to any real financial institution.
